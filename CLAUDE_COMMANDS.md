# Шпаргалка по командам Claude Code

> Актуальный список для вашей версии всегда показывает команда `/help`.
> Набор команд меняется от версии к версии, поэтому часть из них может отличаться.

## Запуск из терминала

| Команда | Описание |
|---|---|
| `claude` | Запустить интерактивную сессию в текущей папке |
| `claude "задача"` | Запустить сессию и сразу отправить первый запрос |
| `claude -p "запрос"` | Неинтерактивный режим: выполнить запрос, вывести ответ и выйти (удобно для скриптов) |
| `claude -c` | Продолжить последний диалог в этой папке |
| `claude -r` | Выбрать и возобновить один из прошлых диалогов |
| `claude --model <имя>` | Запустить с указанной моделью |
| `claude update` | Обновить Claude Code |
| `claude mcp` | Настроить MCP-серверы (внешние инструменты и интеграции) |

## Слэш-команды внутри сессии

### Основные

| Команда | Описание |
|---|---|
| `/help` | Справка и список всех доступных команд |
| `/clear` | Очистить историю диалога и начать заново |
| `/compact [инструкции]` | Сжать историю в краткое резюме, чтобы освободить контекст |
| `/context` | Показать, сколько контекста занято и чем |
| `/resume` | Возобновить один из предыдущих диалогов |
| `/rewind` | Откатить диалог и/или изменения в коде к более ранней точке |
| `/export` | Экспортировать диалог в файл или буфер обмена |
| `/exit` | Выйти из Claude Code |

### Настройки

| Команда | Описание |
|---|---|
| `/config` | Открыть настройки (тема, режимы и т.д.) |
| `/model` | Сменить модель |
| `/fast` | Включить/выключить быстрый режим |
| `/permissions` | Управлять разрешениями для инструментов (что можно делать без подтверждения) |
| `/memory` | Редактировать файлы памяти (`CLAUDE.md`) |
| `/hooks` | Настроить хуки: автоматические действия до/после вызова инструментов |
| `/agents` | Управлять субагентами |
| `/mcp` | Посмотреть и настроить MCP-серверы |
| `/add-dir` | Добавить ещё одну рабочую папку в сессию |
| `/statusline` | Настроить строку статуса внизу терминала |
| `/output-style` | Сменить стиль ответов |
| `/vim` | Включить/выключить vim-режим ввода |
| `/terminal-setup` | Настроить терминал (например, Shift+Enter для новой строки) |
| `/ide` | Подключиться к IDE (VS Code, JetBrains) |

### Аккаунт и диагностика

| Команда | Описание |
|---|---|
| `/login` / `/logout` | Войти в аккаунт или выйти из него |
| `/status` | Показать версию, модель, аккаунт и состояние подключений |
| `/cost` / `/usage` | Показать расход токенов или лимиты использования |
| `/doctor` | Проверить установку и настройки на проблемы |
| `/feedback` | Отправить отзыв или сообщить об ошибке |
| `/release-notes` | Показать список изменений в новых версиях |

### Работа с кодом и проектом

| Команда | Описание |
|---|---|
| `/init` | Проанализировать проект и создать `CLAUDE.md` с его описанием |
| `/code-review [уровень]` | Ревью текущих изменений или PR на ошибки (`--fix` сразу исправляет найденное) |
| `/simplify` | Упростить и почистить изменённый код (без поиска багов) |
| `/security-review` | Проверить изменения в ветке на уязвимости |
| `/run` | Запустить приложение проекта и проверить, что изменения работают |
| `/pr-comments` | Показать комментарии к pull request на GitHub |
| `/install-github-app` | Подключить Claude к GitHub-репозиторию (ревью PR, задачи) |

### Автоматизация

| Команда | Описание |
|---|---|
| `/loop [интервал] <команда>` | Повторять запрос или команду с интервалом (например, `/loop 5m /code-review`) |
| `/schedule` | Создать задачу в облаке, которая запускается по расписанию |
| `/fewer-permission-prompts` | Найти частые безопасные команды и добавить их в разрешённые |
| `/artifacts` | Список опубликованных артефактов (веб-страниц) |

## Специальные символы при вводе

| Символ | Описание |
|---|---|
| `@путь/к/файлу` | Сослаться на файл или папку, чтобы добавить его в контекст |
| `! команда` | Выполнить shell-команду прямо в сессии; её вывод попадёт в диалог |
| `/` | Открыть список слэш-команд |
| `\` + `Enter` | Перенос строки без отправки сообщения |

## Горячие клавиши

| Клавиши | Описание |
|---|---|
| `Esc` | Прервать текущий ответ или действие |
| `Esc` `Esc` | Открыть меню отката к предыдущему сообщению |
| `Shift+Tab` | Переключать режимы: обычный → автопринятие правок → режим планирования |
| `Ctrl+C` | Отменить ввод; нажать дважды, чтобы выйти |
| `Ctrl+D` | Выйти из сессии |
| `Ctrl+L` | Очистить экран (история сохраняется) |
| `Ctrl+R` | Поиск по истории введённых запросов |
| `Ctrl+O` | Показать подробный лог работы (вызовы инструментов) |
| `Ctrl+B` | Отправить выполняемую команду в фон |
| `↑` / `↓` | Листать историю введённых запросов |

## Полезно знать

- **`CLAUDE.md`** в корне проекта — инструкции, которые Claude читает в начале каждой сессии (стиль кода, команды сборки и тестов и т.д.).
- **Свои слэш-команды и навыки** можно добавить в `.claude/skills/` (в проекте) или `~/.claude/skills/` (для всех проектов).
- **Горячие клавиши** настраиваются в `~/.claude/keybindings.json`.
